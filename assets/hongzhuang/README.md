# 红妆阁 · 标准妆造库

> 定位：妆造选择阶段的标准资产。用户**不看自己的脸**选妆，在标准模特「小霓」的
> 12 款妆造图中选款，选定后再把妆容 1:1 迁移到客户脸上。
>
> 起因（2026-07-29 小徐试点）：直接用客户脸做妆造样例，客户觉得"老气"、又说不清
> 要什么，只说"没有海马体化妆师画的好看"。结论：选妆阶段必须与客户本人形象解耦，
> 用标准模特呈现妆效，降低用户的表达成本。

## 结构

- `model_anchor.png` — 标准模特「小霓」素颜锚点图（虚拟人物，无肖像权问题）
- `styles/hz001.png` ~ `hz012.png` — 12 款妆造图，全部以锚点图为参考生成，唯一变量是妆容
- `index.json` — 每款妆造的元数据：系列/vibe/适合场景/美颜参数/提示词键（prompt_key）
- `index.html` — 选妆目录页（移动端友好，可直接嵌入小程序 web-view 或部署线上）
- `gen_anchor.py` / `gen_styles.py` — 生成脚本（从 `tools/luckynemo-toolkit/` 目录下运行）

## 设计原则

1. **减龄优先**：奶油肌/水光肌、低饱和、毛流感眉毛、卧蚕、玻璃唇。
2. **避免老气三件套**：厚重正红唇、强修容、粗黑眼线（港风款是刻意保留的浓妆例外）。
3. **迁移红线**：落到客户脸上时只改妆不改脸，五官脸型零改动；定妆照需人工对照客户照片验收。

## 使用流程（对接小程序四步流程 Step 1）

1. 用户在选妆目录页挑款（看小霓的妆效，不看自己的脸），**点击卡片可看完整妆容说明书** → 记录妆造编号（如 hz004）。
2. 生产端用通用定妆照生成器出「妆造定妆照」：
   ```bash
   cd tools/luckynemo-toolkit
   python3 ../../assets/hongzhuang/gen_dingzhuang.py hz004 --ref /path/客户照片.jpg --out /path/输出目录
   ```
   人工对照客户照片验收（像本人是硬门槛）。
3. 定妆照作为后续婚纱照/短片所有生成任务的脸部锚点。
4.（可选增值）参照《妆容指南》格式，基于客户脸型分析出一份个人专属妆容说明书。

## 定妆提示词：五维配方模板

源自《妆容指南》（妆容指南.jpg）的拆解方法，定妆提示词不再是笼统一段描述，
而是由 `index.json` 中每款的 `spec.parts` 五维配方组装（`build_prompt.py`）：

```
人物锁定（五官/脸型/下颌线/发型不变 + 摘镜声明）
+ 底妆配方 + 眼妆配方 + 腮红配方 + 唇妆配方
+ 整体妆感要求（vibe + 绝不老气）
+ 摄影规格 + 红线（不改脸/无饰品/无水印）
```

效果验证（2026-07-29 小徐 hz002）：v3（五维配方版）脸型保真度优于 v2（笼统描述版），
水光肌/卧蚕/唇妆细节也更到位。
