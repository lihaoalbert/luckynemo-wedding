## 入库品控规则

1. 样板图分两层：**展示图**（单视图，网页浏览用，`nz-001.png`）与**生产参考图**
   （16:9 三视图，正面/侧面/背面同框，`nz-001_3view.png`，垫单视图为参考生成，
   保证与展示图是同一件衣服）。定妆照/婚纱照/短片换装引用一律用三视图
2. 样板图规格：人台展示，纯色浅灰背景，柔光，全身（鞋履/配饰可特写）
3. 每批生成后出品控图墙，逐张审：版型完整、无品牌 logo、无文字乱码、无畸形
4. 不合格重抽（单变量），3 次不过换描述
5. `qc.status`: pending → approved / rejected；只有 approved 可被试衣间引用
