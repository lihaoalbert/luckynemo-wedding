# Seedance 提示词生产规则（distilled）

> 来源：github.com/Emily2040/seedance-2.0（MIT © 2026 Iamemily2050），2026-07-22 获取；
> 结合本工作室 2026-07-21 首单实测（三视图参考、左右舵穿帮、审核误伤、口型问题）修订。
> 本文档是 script_pipeline / video_pipeline 写 prompt 时的执行规则，不是参考资料。

## 一、I2V 核心规则（首帧图生视频）

1. **只写画面里没有的东西**：首帧已包含人物长相、服装、构图、色调，重述会引发漂移。
   video_prompt 只写：动作、运镜、光线变化、时间推进、锁定约束。
2. **动作必须从首帧接着演**：首帧是什么状态，动作就从那个状态开始，
   禁止写"推门进入""悄悄走近"这类首帧之前发生的动作。
3. **每镜最多 2-3 个动作节拍**：6-10 秒塞超过 3 个动作必崩；
   关键情绪节拍至少给 2 秒落地（仓促的情绪读起来像故障）。
4. **一镜一个场景**：禁止单镜内换场景（高架→住宅区这种跳场不稳，拆成两镜）。

## 二、锁定与防漂移

- 人物镜头必带：`人物五官与首帧保持一致`
- 双人镜头必带：`画面中仅这一男一女`（防分身，参考多视图时尤其要加）
- 易碎锚点精确锁：`保持发型服装不变` / `保持房间布局不变`，只锁必须稳的，别全锁（场景需要自然运动）
- 手部易畸形：简化手部动作，或让手避开主要动作区

## 三、音画策略（本工作室默认画外音方案）

- 旁白走克隆音色后期混流（generate_audio=False），音画同出用不了克隆音色
- **narration 是角色台词时**（求婚、誓词），video_prompt 禁止出现"说/读/告白/哽咽着说"，
  改为"无人说话，眼神和动作交流"——观众会默认台词在现场说，口型必穿帮
- narration 是回忆讲述时，画面里环境性交谈（吃饭聊天）可以保留，属"往事重现"语法
- 若未来要用音画同出：台词格式 = 角色名+动作+冒号+引号台词，一镜一句短台词，先确认界面已启用唇形同步

## 四、内容安全与误伤处理

- 真人参考素材过审策略：减少同框正脸数量、非关键人物只给背影/侧影（首单镜头 6 实测有效）
- 误伤修复原则是"澄清生产语境"，不是隐藏意图：把模糊表述改成明确的安全场景描述
- 禁止用文字技巧绕过审核

## 五、套话改写表（写 frame_prompt / video_prompt 时自查）

| 禁止写 | 改写为 |
|---|---|
| 电影感 | 景别+运镜+光源+调色：`宽幅远景，缓慢推镜，低角度暖阳，低饱和青橙调` |
| 氛围感 | 制造氛围的物理元素：`薄雾、逆光轮廓、湿润地面反光` |
| 高级感 | 光线与材质行为：`柔和侧光、受控反光、干净背景` |
| 质感（单用） | 指明哪种：`磨砂玻璃、丝绒吸光` |
| 超高清/8K/杰作/顶级品质 | 删除；分辨率和质量不是请求出来的 |
| 唯美/绝美/震撼/史诗级 | 写出最重要的那一个视觉细节 |
| 她非常悲伤（抽象情绪） | 外化：`低头、肩膀微颤、泪水在眼眶打转但没落下` |
