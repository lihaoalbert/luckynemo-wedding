# 婚纱照品控 Checklist

每张交付图逐项过一遍；任何一项不过 → 打回（重抽或交互编辑精修）。
reroll 纪律：每张图限抽 3 次，抽不到换构图/换提示词，不硬抽。

## 自动初筛（先于人工）
- [ ] ArcFace 相似度 ≥ 内部阈值（0.4-0.6 区间，需用自有样本校准；未装 insightface 时跳过）

## 人工逐项
- [ ] 两人都像本人（家属能一眼认出）
- [ ] 五官无畸变、无"换脸感"
- [ ] 手部正常（AI 婚纱照三大翻车点之一，逐张放大检查）
- [ ] 饰品/服装无漂移、光影方向一致
- [ ] 双人合照无"两个新郎/新娘"错位
- [ ] 无低俗/违和背景元素

## 交付前
- [ ] 图尾"AI 生成"显式标识已加（delivery.py，文字高度 ≥ 最短边 5%）
- [ ] 隐式元数据 sidecar 已生成（.aimeta.json）
- [ ] manifest.json 交付清单已生成
