# 短片品控 Checklist

先逐镜过，再整片过；打回重抽遵循文末「重拍纪律」。

## 逐镜头
- [ ] 角色跨镜头一致（脸/发型/服装）
- [ ] 无穿模（双人互动镜头重点查）
- [ ] 首帧与分镜意图一致（构图/情绪/光线）
- [ ] 动作节拍完成（每镜 2-3 个设计动作都落地，无仓促感）
- [ ] 口型红线：narration 是角色台词的镜头，画面中人物无说话动作（画外音方案，见 templates/seedance_prompt_rules.md §三）

## 整片
- [ ] 旁白无错字、人名读音正确
- [ ] 字幕无错别字、时间轴不压画面主体
- [ ] 转场节奏符合模板（起承转合时间点）
- [ ] 配乐为授权曲库（不可用无商用授权来源）

## 重拍纪律（retake protocol）

每个 take 给五选一判词：**锁定**（主目标达成就过，次要瑕疵归后期）/ **后期修**（调色、字幕、首尾几帧抖动，别烧重拍）/ **编辑不重生成**（只有一层错就换那一层）/ **重抽**（prompt 对、运气差，同 prompt 换 seed，最多 2-3 次）/ **改 prompt**（同一缺陷出现 2 次 = 系统性问题，必须改词）。

- **单变量规则**：每次重拍只改一个东西（一条 prompt 子句 / seed / 模式 / 一张参考图），一次改两个结果不可读
- **尝试预算**：开拍前定死（默认定稿每镜 5 次、草稿 10 次）和"够用"标准；预算过半无进展就换策略（拆镜、换模式、换方案）
- **拍摄日志**：每 take 一行：`Take N · 改了什么 · seed同/新 · 判词 · 一句证据`
