## 一句话风格定义

韩式 pre-wedding photo film：把一组高调布光的婚纱照用"每镜一个姿势、缓慢呼吸感运动"串成短片，像一本会动的婚纱相册。

## 叙事骨架（六段式，镜头数可 ±2）

1. **开场·细节（≈4 镜）**：交握的手与戒指 → 头纱下的侧脸 → 新郎整理领结 → 逆光剪影捧花。全是无正脸或半遮脸的特写，制造期待。
2. **白色房间（≈7 镜）**：全片主体。高调过曝白室内、落地窗光，坐姿/沙发/地毯/窗台/抱起旋转/露背回眸，每镜一个经典韩式姿势。
3. **黑白间奏（≈2 镜）**：突然切黑白——新郎捧花肖像、侧脸花枝。节奏喘息点，艺术感来源。
4. **躺在云上（≈4 镜）**：正上方俯拍，新娘/双人躺在蓬松白纱上，花瓣。全片记忆点最强的段落。
5. **夜街（≈3 镜）**：唯一外景、唯一暗调段落：霓虹散景牵手走 → 斑马线奔跑 → 亲吻。彩色→黑白。
6. **收尾（1 镜 + 字卡）**：黑白吻定格 → 黑底白字卡。

## 视觉 DNA（写 frame_prompt 的配料表）

- **布光**：高调（high-key）、落地窗柔和侧光、大量过曝白；夜景段是唯一的低 key，用暖色实用灯 + 霓虹散景
- **色调**：低饱和奶油色（米白/象牙/浅驼），胶片颗粒；黑白段为高对比细腻影调
- **构图**：竖构图、浅景深、大量留白；人物偏中近景，俯拍段必须"正上方"
- **服装**：新娘白纱（抹胸/露背/蕾丝袖轮换）+ 头纱 + 满天星捧花；新郎黑西装（室内）/ 白衬衫黑西裤（休闲镜）
- **运动**（video_prompt）：每镜 1-2 个微动作节拍——"缓缓、轻轻、静止两秒"是关键词；运镜只用"极缓慢推近/拉远/横移/横向稳定跟拍"，禁止快剪感
- **节奏**：彩色段慢，黑白段更慢，夜街段是唯一有速度（走/跑）的段落，最后回到静止的吻

## 与爱情叙事短片（lovestory 线）的区别

| | 婚照电影（本 skill） | 爱情叙事短片（film-sop） |

| 内容 | 婚纱照姿势流，无剧情 | 有故事线的剧情分镜 |
| 声音 | 纯 BGM | 克隆声音旁白 + BGM |
