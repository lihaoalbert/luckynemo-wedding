# 「AI 小导演」产品形态：从生成照片到导演拍摄

> 日期：2026-09-24
> 状态：一期（证件照场景）已实施于 `idphoto` 分支，待真机验证与发布；本文档同时是二期（剧本关卡/双人拍摄/运镜指导）的方向存档。
> 上游调研：`research/2026-09-目标市场拓展调研-中老年与证件照.md`（人群与市场）；竞品与技术验证见本文 §四。

## 一、核心概念

**镜头对着被拍者，屏幕对着持机的"摄影师"（普通人），AI 当现场导演**。AI 在拍摄过程中就参与：屏幕上实时指引怎么拍、怎么运镜、怎么指挥被拍者。

- 证件照场景的目的：让拍照更合规（拍的时候就达标，不会被驳回）；
- 其他场景的目的：让过程更好玩（参与感、被夸奖、一起完成一件事）。

去老年感的关键：产品语言永远从"摄影师视角"切入（"给妈妈拍大片""闺蜜互拍"），不贴人群标签；界面语言是"导演监视器"，大字可爱像小游戏，但不是"老年模式"。

## 二、AI 小导演三通道

1. **屏幕指引（给摄影师）**：实时框线 overlay（头部椭圆/双肩线/头顶留白）+ 大字指令（"手机往左一点"）；
2. **台词卡（给摄影师喊出来）**：把"不会指挥"变成照台词念（"喊：想想一会儿吃啥好吃的"）；
3. **语音夸奖（外放给被拍者）**：TTS 现场夸人——"这个角度绝了！"被夸奖是被拍者放松笑出来的开关，是差异化灵魂。

## 三、一期实现（证件照，idphoto 分支）

三拍骨架：**选规格大卡 → 拍一拍（达标自动抓拍）→ 2 元导出**。

- **规格库** `miniprogram/utils/idphoto_specs.js`：20+ 规格（常用/考试报名/签证出行/职业四组），含像素尺寸与头部占比参数；
- **规则引擎** `miniprogram/utils/idphoto_rules.js`：端侧纯规则判定（脸宽占比 0.28–0.45、中心偏移 <8%、roll<10°、yaw<15°、亮度 90–190、左右半脸亮度差判阴阳脸），输出指令枚举 + 大字 hint + 台词卡；连续约 1s 达标 → 「保持不动」→ 3-2-1 自动抓拍；
- **端侧检测** `miniprogram/utils/face_detect.js`：BlazeFace（tfjs 插件 tfjsPlugin + npm 注入），roll 用双眼连线夹角、yaw 用鼻尖偏移近似；**全链路降级**：npm 未构建/插件未加/模型加载失败 → 手动模式（对准框线自己按快门），功能不阻塞；
- **TTS** `POST /api/mp/tts`：MiniMax t2a（toolkit synthesize 惰性导入），`md5(voice+text)` 存 OSS `tts/` 永久缓存，命中秒回；限流 30 次/分钟/openid；音色常量 `TTS_VOICE_ID="presenter_female"`（待定，用户拍板）；
- **计费隔离**：`VP_PRODUCTS` 新增 `idphoto2`（2 币/1 张），`mp_orders.idphoto_count` 专用额度列（新单默认 1 次免费），`_vp_grant`/iOS 退款回收按 `grant_field` 路由——2 元商品不污染写真 paid_count 池；
- **worker `idphoto` 任务**：rembg（u2net_human_seg，CPU）抠图 → 白/蓝/红标准色换底 → 按 face_box 居中裁剪排版 → `results/{order_no}/`；实测发丝边缘干净、尺寸精确；
- **合规**：拍摄授权勾选留痕（`idphoto_consent` 事件）、页面常驻「不适用于身份证/护照等官方证件」、一期不做换装/美颜（规避生成式 AI 标识与考试禁精修风险）；
- **埋点**：`idphoto_enter/consent/spec_pick/shot/pass/export_pay/to_moka` 7 事件（白名单 app.py + mp_worker.py 两处）；
- **入口**：chat 页 PAGE_CARDS「证件照 · 2 元起」+ me 页资产区入口行；结果页导流卡「顺便拍套写真」跳模卡（引流主线的钩子）。

## 四、竞品与技术验证摘要（调研于 2026-09-24）

- 静态姿势轮廓叠加（韩国 SOVS，"Don't explain, just SHOW"）2019 年网红化但无 AI；AI 骨骼实时打分（新 PoseCam/AI Posing）与系统级构图建议（华为 Pura 80 AI 构图、Pixel 10 Camera Coach）2025 年密集出现；
- **"屏幕给摄影师 + 语音指挥被拍者"的双人实时指导全球仅 WayShot 一家初创，国内小程序形态无直接竞品**；
- 证件照"合规才放行"有成熟先例（出入境自助一体机实时检测、长春公安"一照通拍"小程序自检）；检测维度（头部占比/双肩水平/光照/背景纯色）商用 API 与 ICAO 9303 开源实现充足；
- 小程序端侧 BlazeFace 实测 60–80ms/帧（iPhone 13），onCameraFrame ~30fps 需节流；「端侧 CV 硬反馈 + 抽帧服务端语义建议」是业界验证架构。

## 五、二期路线（分层决策架构）

实时指引的决策分层（JEV 决策模型范式启发：状态结构化 → 受限枚举决策）：

| 层 | 一期 | 二期 |
|---|---|---|
| 端侧硬反馈（0 延迟） | BlazeFace + 规则引擎 | 同左，加 BlazeFace 全身/手势扩展 |
| 服务端语义判断（1–2Hz） | 无 | 蒸馏私有 2B 视觉决策模型（Qwen3.5-2B 级 LoRA，大 VLM 离线标注训练集；模卡模板=好构图正样本），参考 jev-drone 2.5–3Hz/110ms 中位延迟，需 GPU 实例 |
| 大 VLM | 无 | 关卡开始编排剧本、结束点评——隔离在实时环外 |

二期玩法候选（按优先级）：①写真剧本关卡（关卡=模卡变体，九宫格从"买 9 张"变"拍 9 关"）②双人送礼拍摄（子女=摄影师拍爸妈，成片晒关系）③运镜指导接 storylab（屏幕叠运镜轨迹，拍完进剪辑管线）④远程导演（live-pusher RTC，**类目资质大概率申请不到，退 WebSocket 低帧率截图方案，立项前先确认**）。

## 六、遗留与风险

- MiniMax 账号 Token Plan 已用尽（2026-09-24 实测 2056 错误），TTS 上线前需充值/换 key；
- ECS 需 `pip install rembg onnxruntime`，并预置 u2net 模型（github 直连慢，用 hf-mirror 下载，`U2NET_HOME` 指向预置目录）；
- tfjsPlugin 需在 MP 后台添加插件，版本号以插件市场实际为准；模型在线加载国内可达性未验证（备选：权重传自有 OSS 改 MODEL_URL）；
- 真机验证清单：帧率/发热、低端机性能、旧基础库 canvas 同层渲染兼容、相机权限引导；
- MP 后台新建 2 元金币商品（已发布商品不可改价，必须新建）；
- 抖音版（miniprogram-douyin/）双端移植未做，单独立项。
