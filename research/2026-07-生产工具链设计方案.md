# 徐大恩（LuckyNemo）AI 婚庆影像生产工具链设计方案

- 设计时间：2026-07-20
- 底座：火山引擎方舟（Seedream 5.0 系列图片 + Seedance 2.0 视频）
- 依据：4 路并行调研（Seedance 2.0 / Seedream / 配音脚本后期 / 工作室 SOP 合规），关键事实均附来源；查不到的已标注
- 目标读者：创始团队；本文是"怎么干"的施工图纸，不是市场分析

---

## 0. 一页结论

1. **先解决"真人脸"准入，这是一切的前提。** Seedance 2.0 明确规定**不支持直接上传含真人人脸的参考图/视频**，必须经方舟控制台「录入真人形象素材」（人脸核验 + 肖像授权）后才能用于生成（[官方文档](https://www.volcengine.com/docs/82379/2315856)、[中证金牛座](https://jnz.cs.com.cn/app/html/jnz/119566.html)）。婚庆业务 100% 是真人，**工具链第 0 步就是把"客户授权 → 形象录入"做成标准动作**。Seedream 图片侧未见同等强制说明，但建议按同一标准执行。
2. **工具形态定为"云 API + Python 脚本 + 多维表格管单"，不自建 ComfyUI。** 与 2026 年主流商业团队一致（[36氪](https://m.36kr.com/p/3827470501122690)）：无 GPU 运维负担，标准化做在提示词模板库、分镜模板、品控 checklist 上。
3. **三条产品线共用一套中台**（订单/素材/授权/品控/交付/删除），差异只在"生成管线"模板。
4. **成本复核（按官方价）**：AI 婚纱照 10 张套图算力 ≈ 10 元；3 分钟短片算力 ≈ 200-350 元（草稿用 Mini、成片用标准版）；配音/字幕/配乐 ≈ 5 元。售价 299/999 对应毛利 65-95%，**成本大头仍是人工**。
5. **AI 标识责任在我们**：Seedance API 的显式水印参数默认**关闭**，Seedream 默认开启；显式+隐式双标识（GB 45438-2025）必须写进交付脚本，不能靠平台默认。
6. **配乐不用海绵音乐（无商用授权）、配音不用剪映朗读（商用授权存疑）**：配音走豆包 TTS，配乐走 1 元/首的授权曲库。
7. **人效基准（行业数据推算）**：短片 1-3 人日/条、婚纱照 0.5-1.5 人日/套；每镜头限抽 3 次 reroll，抽不到换构图不硬抽。

## 2. 总体架构：一套中台 + 三条管线

```
┌─────────────────────────────────────────────────────────┐
│  中台（三条产品线共用）                                    │
│  飞书多维表格订单台 ─ 表单收图 ─ 素材库(对象存储)            │
│  授权管理 ─ 形象录入台 ─ 品控看板 ─ 交付台 ─ 定时删除         │
└─────────────────────────────────────────────────────────┘
        │                │                │
  ┌─────▼─────┐   ┌──────▼──────┐   ┌─────▼──────┐
  │ 管线 A     │   │ 管线 B       │   │ 管线 C      │
  │ AI 婚纱照  │   │ 爱情叙事短片  │   │ 领证纪念    │
  │ (Seedream) │   │ (SD+SD2.0)  │   │ (模板化)    │
  └───────────┘   └─────────────┘   └────────────┘
```

**原则**：中台管"流程与合规"，管线管"生成与质量"。所有管线共用同一套脚本工具包（`luckynemo-toolkit`，Python），只是模板不同。

## 3. 中台设计（先做，1 周内可落地）

### 3.1 订单台：飞书多维表格

一张表管全部订单，字段即 SOP 状态机：

| 分组 | 字段 |
|---|---|
| 客户 | 称呼、微信、婚期、产品线（婚纱照/短片/领证）、SKU 档位 |
| 合规 | 授权书已签□、人脸单独同意□、形象已录入□、宣传授权□（单独！） |
| 素材 | 表单链接、素材文件夹、素材质检通过□ |
| 生产 | 当前工序（下拉：待质检/生成中/品控中/精修中/待交付）、负责人、reroll 计数 |
| 交付 | 初稿链接、修改意见、终稿链接、交付日期、**删除日期**（交付+N 天自动算） |
| 财务 | 实收、算力成本、人工工时、毛利 |

视图按工序分："待办看板"（按工序分组）、"本周交付"、"待删素材"（删除日期 ≤ 今天）。飞书多维表格 2025-08 起可脱离飞书独立使用（[来源](http://mp.weixin.qq.com/s?__biz=MzI3NTY4MjcxNg==&mid=2247488083&idx=1&sn=3b899a3c4c285b5ef36feaa73642e694)）。

### 3.2 收素材：表单 + 对象存储

- 用表单工具（金数据/飞书问卷）收图：图片字段限制 6-15 张、JPG/PNG、单张 ≤20MB（[金数据附件字段](https://jinshuju.net/help/articles/upload-file)）
- **表单里嵌合规文案**：人脸信息单独同意为**独立勾选**（GB/T 45574-2025 要求独立页面/独立勾选，[解读](https://zhuanlan.zhihu.com/p/1909198428556208112)），不与服务协议捆绑
- 素材落对象存储（火山 TOS/OSS），按 `客户ID/日期` 分目录；**生命周期规则设交付后 30 天自动删除**——这是"交付即删"承诺的工程实现（行业无成文实践，对象存储生命周期是通用做法）

### 3.3 形象录入台（Seedance 真人路径）

标准动作，每客户一次：

1. 授权书签收（电子签或拍照回传）→ 多维表格勾选
2. 方舟控制台「录入真人形象素材」：客户本人人脸核验 + 肖像授权（[官方流程](https://www.volcengine.com/docs/82379/2315856)）
3. 录入后的形象 ID 记入订单行，生成任务引用
4. 交付完成后按协议期限注销形象素材

**注意**：此功能的开通门槛（企业认证/保证金/新签限制）是头号商务风险，第 0 周就要向火山商务确认清楚（见 §8）。

### 3.4 品控看板

- **自动初筛**：每张交付图过 InsightFace/ArcFace 与客户原片 1:1 比对，低于内部阈值打回（阈值用自有样本校准，工程经验区间 0.4-0.6，需自测，[InsightFace](https://www.insightface.ai/)）
- **人工 checklist**（每条产品线一版，见 §4-6）：行业无公开 AI 验收标准（已确认查不到），这是我们自己的质量资产
- **reroll 纪律**：每镜头/每张图限抽 3 次，抽不到换提示词或换构图；reroll 计数入多维表格，超 3 的单要复盘原因（[行业惯例](http://www.iceo.com.cn/article/b1a7819f-ff9c-4985-a357-3b439a81a555)）

### 3.5 交付与删除

- 交付物双版本：16:9 横版（婚礼大屏）+ 9:16 竖版（朋友圈/抖音），另加 15 秒预告竖版（行业惯例，[猪八戒服务页](https://m.zbj.com/shop/37598866/sid-2190188.html)）
- 网盘链接交付，底片全量给（婚摄行业标准，[山东消协指南](https://www.ea360.com/contents/22/37356.html)）
- 交付 N 天后：TOS 生命周期自动删源素材 → 多维表格记删除完成 → 形象素材注销
- 所有交付文件必经"标识脚本"（见 §7）

## 4. 管线 A：AI 婚纱照（SKU：29.9 尝鲜 / 299 套图）

**目标人效**：一套 10 张套图 ≤ 1 人日；尝鲜款 ≤ 1 小时。

### 4.1 流程（7 步）

1. **素材质检**（人工 5 分钟）：checklist = 每人 ≥4 张清晰正脸、无墨镜/遮挡、光照均匀、分辨率 ≥1024。不合格直接打回重传（参考图质量是相似度第一变量，[实践结论](https://fengyiyi.com/2025/12/09/Seedream4-5.html)）
2. **选风格**：从风格模板库选（初版 6 套：室内主纱、森系外景、中式秀禾、旅拍海边、韩式极简、复古胶片）
3. **批量生成**：脚本调 Seedream 5.0 Pro，参考图 = 客户照片（≤10 张），每风格出 2 张候选；双人同框用多图融合
4. **初筛**：ArcFace 相似度自动比对 + 人工过一遍（五官/手部/穿帮）
5. **精修**：局部问题用 5.0 Pro 交互编辑（圈选手部/饰品重绘），不再整图重抽
6. **标识 + 交付**：显式水印按交付版本策略加（§7），网盘交付
7. **修改**：含 2 次免费修改（婚摄行规），修改走交互编辑，成本极低

### 4.2 工具：`photo-pipeline` 脚本

- 提示词模板库（YAML，每风格一套：场景描述 + 光线 + 镜头语言 + "保持与参考图同一人物五官脸型"固定语句）
- 批量提交 + 结果落库 + ArcFace 初筛 + 生成"待人工品控"图墙（HTML 页，勾选通过/打回）
- 成本：10 张套图 = 生成约 25 张（含候选与 reroll）× 0.6 元 ≈ **15 元**

### 4.3 婚纱照品控 checklist（初版）

- [ ] 两人都像本人（家属能一眼认出）
- [ ] 五官无畸变、无"换脸感"
- [ ] 手部正常（AI 婚纱照三大翻车点之一）
- [ ] 饰品/服装无漂移、光影方向一致
- [ ] 双人合照无"两个新郎/新娘"错位
- [ ] 无低俗/违和背景元素

## 5. 管线 B：爱情叙事短片（SKU：999 / 1999 / 3999）

**目标人效**：2-3 分钟片 ≤ 2 人日（行业数据 1-3 人日，[来源](http://www.iceo.com.cn/article/b1a7819f-ff9c-4985-a357-3b439a81a555)）。

### 5.1 流程（9 步）

1. **故事采集**：结构化问卷（相识经过/关键节点/性格细节/想对彼此说的话/父母素材）+ 20 分钟语音访谈（可选）
2. **脚本 + 分镜**：LLM（豆包 Seed 1.6）按剧本模板生成 JSON 分镜表（镜头号/时长/画面/首帧描述/旁白/情绪），**客户确认脚本后再进生成**——这是省 reroll 钱的关键闸门
3. **形象录入**：走 §3.3 真人核验路径（短片管线比婚纱照多这一步强制依赖）
4. **首帧图**：Seedream 按分镜逐镜生成首帧（角色一致性的锚），品控通过后锁首帧
5. **逐镜生成**：Seedance 2.0 图生视频，12-18 个镜头；**草稿用 Mini（0.5 元/秒）、定稿用标准版 720p（0.95 元/秒）**；长叙事用首尾帧接龙；`generate_audio` 先关，配音单独做（可控性更高）
6. **配音**：豆包 TTS 情感音色读旁白；升级项 = 新人本人**声音复刻**（138 元/音色，须本人授权）读告白段落——这是 3999 档的核心卖点
7. **粗剪**：FFmpeg 脚本按分镜表拼接 + 授权配乐 + 字幕（豆包 ASR 打轴）
8. **人工精剪**：pyJianYingDraft 导出剪映草稿，人工调节奏/转场/调色，约 2-4 小时
9. **标识 + 双版交付**：16:9 完整版 + 9:16 竖版 + 15 秒预告

### 5.2 剧本模板库（三个产品各一套）

- **成长故事**：童年照片修复动态化 → 相遇 → 相恋 → 求婚（老照片动态化是已验证爆款公式）
- **爱情故事**：相识场景 AI 重现 → 关键节点蒙太奇 → 告白
- **感恩父母 + 亲友祝福**：成长照片 → 父母旁白 → 亲友祝福合集（对口型）

每套模板固定：镜头数、节奏曲线（起承转合时间点）、旁白结构、配乐情绪点。**模板即质量稳定性**，新客单 80% 走模板，20% 定制。

### 5.3 短片品控 checklist（初版）

- [ ] 角色跨镜头一致（脸/发型/服装）
- [ ] 无穿模（双人互动镜头重点查）
- [ ] 口型与配音对得上（行业口型精度约 85%，关键台词人工修）
- [ ] 旁白无错字、人名读音正确（豆包 ASR 校对人名）
- [ ] 字幕无错别字、时间轴不压画面主体
- [ ] 片尾"AI 生成"声明卡 ≥2 秒（GB 45438-2025）

### 5.4 短片成本复核（3 分钟，官方价）

| 项 | 计算 | 金额 |

## 7. 合规与标识的工程落地（写进脚本，不靠人记）

1. **显式标识**：交付版统一策略——片尾/图尾加"AI 生成"标识卡（视频 ≥2 秒、文字高度 ≥ 画面最短边 5%，[GB 45438-2025](https://www.sohu.com/a/944267344_121964487)）；客户要"无水印纯净版"走《标识办法》第 9 条豁免：协议明确用户义务 + **日志留存 ≥6 个月**
2. **隐式标识**：交付脚本调用开源 [cnTC260](https://github.com/OPN48/cnTC260) 写入国标五要素元数据；同时开通方舟隐式水印（Beta 限时免费）双保险
3. **授权文件三件套**（律师过一遍再启用）：服务协议（含素材保存期限与交付后删除条款）+ 人脸信息单独同意书（独立勾选）+ 肖像授权书（区分"仅制作"与"可用于宣传"，宣传授权单独签）
4. **声音复刻**：仅本人在场录音授权，不为他人代录；已故亲属声音/形象默认不做（红线，见市场调研报告）
5. **宣传素材**：发小红书/抖音的案例必须另有宣传授权，且保留 AI 标识（网络传播场景）
